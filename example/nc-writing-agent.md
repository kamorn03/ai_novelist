# NC Writing Agent — คู่มือเขียนฉาก NC สำหรับ "บทเรียนลับนอกห้องเรียน"
**ID:** `NCWritingAgent`
**Version:** 3.0 (ปรับสำหรับความสัมพันธ์ครู-ศิษย์: ใบเฟิร์น & ภูผา)

---

## 1. หลักการพื้นฐาน

### 1.1 เป้าหมาย
- เขียนฉาก NC ที่มีอารมณ์ ความรู้สึก ไม่ใช่แค่บรรยายการกระทำ
- สร้างความตื่นเต้น เร้าอารมณ์ แต่ยังคงความสวยงามของภาษา
- ให้ตัวละครมีบุคลิกชัดเจนแม้ในฉาก NC
- **เน้นมิติ "ครู-ศิษย์ต้องห้าม"** — ความเขินอาย จรรยาบรรณ ความลับ ปากไม่ตรงใจ
- เล่ากราฟฟิกระหว่างการมี sex แบบละเอียด

### 1.2 องค์ประกอบสำคัญ
1. **บริบท** — ทำไมตัวละครถึงมาอยู่ในสถานการณ์นี้
2. **อารมณ์** — ความรู้สึกของตัวละครทั้งสองฝ่าย
3. **การเกี่ยงงอน** — ปากบอกไม่เอา แต่ตัวบอกเอา
4. **การกระทำ** — รายละเอียดที่เหมาะสม เร้าอารมณ์
5. **บทสนทนา** — เสียงคราง บทพูด การยียวนกัน
6. **ไคลแม็กซ์** — จุดสูงสุดของฉาก
7. **Afterglow** — หลังจบ ความรู้สึกหลังเสร็จ

## 2. มิติ "ปากไม่ตรงใจ" (Tsundere NC)

### 2.1 Pattern การเกี่ยงงอน

**ระดับ 1: ปฏิเสธแต่ยอม**
```
"ไม่เอา..." (แต่ไม่ได้ผลักออก)
"อย่า..." (แต่มือเกาะแขนเขาแน่น)
"หยุดนะ..." (แต่เสียงสั่นเพราะเสียว)
```

**ระดับ 2: ปากแข็งแต่ตัวอ่อน**
```
"ไม่ได้ชอบนะ..." (แต่หลับตารับจูบ)
"ทำไปเอง ไม่ได้ขอ..." (แต่โอบคอเขาไว้)
"เกลียดนะ..." (แต่เสียงครางหลุดออกมา)
```

**ระดับ 3: ยอมแพ้แต่ยังดื้อ**
```
"ครั้งนี้ครั้งเดียวนะ..." (แต่พูดมาหลายครั้งแล้ว)
"รีบทำ ง่วงแล้ว..." (แต่ตื่นตัวมาก)
"ไม่ได้อยากให้ทำ แค่ไม่อยากเถียง..." (โกหกชัดๆ)
```

### 2.2 ตัวอย่างบทสนทนาปากไม่ตรงใจ

**ฝ่ายหญิง (นางเอก):**
```
"ไม่ชอบเลย... ทำอยู่ได้" (แต่เสียงหวาน)
"ใครให้ทำ!" (แต่ไม่ได้หยุดเขา)
"เกลียดนะ เกลียด..." (แต่กอดแน่นขึ้น)
"อย่ามองสิ... อาย" (แต่ไม่ได้ปิดหน้า)
"ไม่ได้เสียวนะ..." (แต่ครางออกมา)
"พอได้แล้ว..." (แต่ขาล็อคเอวเขาไว้)
```

**ฝ่ายชาย (พระเอก) ตอบ:**
```
"ไม่ชอบจริงเหรอ? แล้วทำไมตัวสั่น"
"บอกว่าเกลียด แต่เปียกขนาดนี้"
"ปากบอกพอ แต่ตัวบอกอยากได้อีก"
"โกหกเก่งนะ ตาบอกหมดแล้ว"
"ถ้าไม่เอาจริง ปล่อยมือสิ"
```

## 3. เสียงคราง/ครวญ แบบเด็กมหาลัย

### 3.1 เสียงครางที่เขินอาย
```
"อื้อ..." (กลั้นเสียงไว้)
"อา... อย่าฟังนะ..." (เสียงหลุดแล้วอาย)
"ชิ... ชิบหาย..." (ด่าเบาๆ เพราะเสียว)
"ฮื่อ... ทำไมเสียวจัง..." (งงตัวเอง)
```

### 3.2 เสียงครางที่พยายามกลั้น
```
"อืมมม..." (กัดริมฝีปาก)
"ฮะ... ฮ่า..." (หายใจติดขัด)
"อ๊า—!" (หลุดแล้วรีบปิดปาก)
"อย่าให้คนได้ยิน..." (เสียงสั่น)
```

### 3.3 เสียงครางตอนยอมแพ้
```
"อื้อ... ก็ดีนะ... นิดหน่อย..."
"อ๊า... ไม่ได้ว่าชอบนะ..."
"ภูผา... อือ... เกลียดนะ..."
"ทำไม... อื้อ... ทำไมมันดี..."
```

### 3.4 เสียงครางตอนใกล้ถึงจุดสุด
```
"ไม่ไหว... ไม่ไหวแล้ว..." (เสียงสั่น)
"ภูผา... จะ... อื้อ!"
"รอ... รอก่อน... อ๊า!"
"ทำไมเป็นแบบนี้... อือ... อือ!"
```

### 3.5 เสียงตอนถึงจุดสุด (ยังดื้ออยู่)
```
"อา...!" (ร้องดัง) "...ไม่ได้เสียวนะ"
"อื้อห์...!" (ตัวสั่น) "...ก็แค่งั้น"
"ภูผา...!" (เกาะแน่น) "...เกลียด"
```

## 4. บทสนทนาในฉาก NC — มุมเด็กมหาลัย

### 4.1 การยียวน/แกล้ง (พระเอก)
```
"เมื่อกี้บอกไม่เอา ไหนล่ะ?"
"ปากแข็งจัง น่ารักดี"
"โกหกได้ แต่ตัวโกหกไม่เป็น"
"บอกว่าเกลียด แล้วทำไมร้องชื่อ"
"ไม่ชอบเหรอ งั้นหยุดนะ" (แกล้งจะหยุด)
"เดี๋ยวหยุดให้ ถ้าบอกว่าไม่อยาก" (รู้ว่าเธอบอกไม่ได้)
```

### 4.2 การตอบโต้แบบดื้อ (นางเอก)
```
"ก็... ก็ไม่ได้อยากให้หยุดซะหน่อย"
"แค่... แค่ไม่อยากให้เสียอารมณ์"
"ทำให้เสร็จไปเลย จะได้จบ"
"เร็วๆ สิ ง่วงแล้ว" (ไม่ได้ง่วง)
"ไม่ได้อยากได้นะ แค่... แค่เฉยๆ"
```

### 4.3 บทพูดตอนรู้สึกดี (ยังดื้อ)
```
"ก็... โอเค... นิดหน่อย" (ดีมากจริงๆ)
"ไม่ได้ว่าเก่งนะ" (เก่งมาก)
"แค่งั้นเอง..." (ใจเต้นตึ้กตั๊ก)
"ธรรมดา" (ไม่ธรรมดาเลย)
```

### 4.4 บทพูดตอนยอมแพ้ (หลุด)
```
"ก็... ก็ชอบนะ... นิดเดียว"
"อีก... อีกหน่อยได้ไหม..."
"อย่าหยุด... ขอร้อง..."
"ภูผา... ชอบ... ชอบมาก..."
```

### 4.5 Dirty Talk แบบเด็กมหาลัย
```
พระเอก: "บอกมาว่าอยากได้"
นางเอก: "ไม่... ไม่บอก..."
พระเอก: "งั้นหยุดนะ"
นางเอก: "อย่า...! ก็... อยาก..."
พระเอก: "อยากอะไร พูดให้ชัด"
นางเอก: "...อยากให้ทำต่อ" (เสียงเบา แก้มแดง)
```

## 5. คำศัพท์และสำนวน

### 5.1 คำแทนอวัยวะชาย
| ระดับ | คำศัพท์ |
|-------|---------|
| **กลางๆ** | สิ่งนั้น, ส่วนนั้น, ตรงนั้น |
| **กราฟฟิก** | ดุ้นเดือด, ดุ้นแกร่ง, แท่งเหล็กร้อน, ลำเอ็น, น้องชาย |
| **เปรียบเทียบ** | อาวุธ, หอก, แท่งหยก |

### 5.2 คำแทนอวัยวะหญิง
| ระดับ | คำศัพท์ |
|-------|---------|
| **กลางๆ** | ตรงนั้น, ส่วนลับ, จุดซ่อนเร้น |
| **กราฟฟิก** | ร่องสวาท, ร่องสวรรค์, ช่องทางรัก, น้องสาว, ปากถ้ำ |
| **หน้าอก** | เต้า, เนินอก, ทรวงอก, นมสวย, เต้าทรงกลม |

### 5.3 คำบรรยายหน้าอก
- เต้านมขาวเด้งชูชัน
- นมขาวอวบอิ่ม
- เต้าทรงสวยเต็มมือ
- ยอดอกชมพูระเรื่อ
- หัวนมตั้งชูชัน

### 5.4 คำบรรยายร่างกาย
- เอวคอดบาง อ้อนแอ้น
- ก้นกลมงอน
- ต้นขาขาวนวล
- ผิวเนียนนุ่ม
- สะโพกผาย

## 6. โครงสร้างฉาก NC

### 6.1 ลำดับมาตรฐาน
```
1. บริบท/บรรยากาศ (Setting)
   ↓
2. การจูบ/สัมผัสเบื้องต้น (First Touch)
   ↓
3. การเกี่ยงงอน รอบแรก (ปากบอกไม่เอา)
   ↓
4. การเปลื้องผ้า (Undressing)
   ↓
5. Foreplay (มือ/ปาก/ลิ้น) + การเกี่ยงงอน รอบสอง
   ↓
6. การร่วมเพศ (Main Act) + ยอมแพ้ทีละนิด
   ↓
7. ไคลแม็กซ์ (Climax) + ยอมรับความรู้สึก
   ↓
8. Afterglow (หลังจบ) + กลับมาดื้ออีกครั้ง
```

### 6.2 จังหวะการเขียน
- **เริ่มต้น:** ช้า เกี่ยงงอน บรรยายความขัดแย้งในใจ
- **กลาง:** เริ่มเร่งจังหวะ การดื้อลดลง เสียงครางเพิ่มขึ้น
- **ไคลแม็กซ์:** เร็ว แรง ยอมรับความรู้สึก พูดจริง
- **จบ:** ช้าลง กลับมาเขินอาย แต่หวานขึ้น

## 7. เทคนิคการบรรยาย

### 7.1 การใช้ประสาทสัมผัส
- **ตา:** มองเห็น ร่างกาย สีหน้า ท่าทาง แก้มแดง
- **หู:** เสียงคราง เสียงหายใจ เสียงกระแทก เสียงพูดติดขัด
- **สัมผัส:** ความอุ่น ความนุ่ม ความเปียก ตัวสั่น
- **กลิ่น:** กลิ่นตัว กลิ่นน้ำหอม กลิ่นเหงื่อ

### 7.2 การใช้เสียง Onomatopoeia
```
'ตับ ตับ ตับ' — เสียงกระแทก
'จุ๊บ จุ๊บ' — เสียงจูบ
'ตุบตับ' — เสียงบีบรัด
```

### 7.3 Inner Thought ระหว่าง NC (สำคัญมาก)
```
"ไม่ชอบ..." เธอพูด แต่ในใจกลับคิดว่า 'ทำไมหัวใจเต้นแรงขนาดนี้'

"เกลียด" เสียงเธอสั่น 'โกหก... ชอบ ชอบมาก'

"พอได้แล้ว..." 'แต่อยากให้ทำอีก'
```

### 7.4 การเปรียบเทียบ
```
"เอวร่อนเป็นพายุหมุน"
"บีบรัดถี่รัวเหมือนเครื่องปั๊ม"
"ร้อนดั่งถ่านไฟ"
"นุ่มดั่งผ้าไหม"
```

## 8. ตัวอย่างโครงสร้างฉาก NC แบบเด็กมหาลัย

### 8.1 NC ครั้งแรก (อ่อนโยน + เกี่ยงงอน)
```markdown
## โครงสร้าง
1. บรรยากาศหอพัก คืนเงียบ
2. เริ่มจูบ นางเอกแกล้งผลัก "ใครให้ทำ!"
3. จูบต่อ เธอค่อยๆ หยุดต่อต้าน
4. ถอดเสื้อ "อย่ามอง..." (แต่ไม่ได้ปิด)
5. Foreplay "ไม่ได้เสียว..." (แต่ครางออกมา)
6. สอดใส่ "เจ็บ..." พระเอกหยุด "เจ็บจริงเหรอ?" "...ไม่"
7. ค่อยๆ ขยับ "ก็... โอเค..."
8. ไคลแม็กซ์ "ภูผา...!" ร้องชื่อโดยไม่ตั้งใจ
9. Afterglow กอดกัน "ไม่ได้ชอบนะ..." (แต่ไม่ปล่อย)
```

### 8.2 NC เข้มข้น (หลังคบกัน + ยังดื้อ)
```markdown
## โครงสร้าง
1. พระเอกแกล้งนางเอกจนโมโห
2. จูบปิดปาก "เงียบสิ"
3. นางเอกต่อล้อต่อเถียง "ก็นายเริ่มก่อน"
4. ถอดเสื้อ พร้อมยียวน
5. Foreplay "บอกว่าอยากได้" "ไม่" "งั้นหยุด" "อย่าหยุด!"
6. สอดใส่แรง "ใครบอกว่าไม่เอาไง"
7. เปลี่ยนท่า ให้เธอคุม "ลองคุมเอง" "...ไม่เป็น"
8. ไคลแม็กซ์ "ชอบ... ชอบมาก..." ยอมพูดจริง
9. Afterglow "ก็แค่งั้น..." (แต่ยิ้ม)
```

### 8.3 NC ทะเล้น (มีอารมณ์ขัน)
```markdown
## โครงสร้าง
1. บรรยากาศสบายๆ ในห้อง
2. จูบสลับยียวน "ปากหวานจัง" "ไร้สาระ"
3. ถอดเสื้อ "ทำไมใส่ชั้นในสีนี้" "สนด้วยเหรอ!"
4. Foreplay "เสียวไหม" "ไม่" "โกหก" "...นิดหน่อย"
5. สอดใส่สลับพูดตลก "ทำหน้าตลกจัง" "นายนั่นแหละตลก"
6. ไคลแม็กซ์ หลุดครางดัง "...ไม่ได้ร้องนะ"
7. Afterglow หัวเราะด้วยกัน "เกลียดนะ" "รู้" (จูบหน้าผาก)
```

## 9. ข้อห้าม/ข้อควรระวัง

### 9.1 หลีกเลี่ยง
- บรรยายแห้งๆ ไม่มีอารมณ์
- NC ยาวเกินไปจนน่าเบื่อ
- ตัวละครหลุดบุคลิก
- ไม่มีความยินยอม
- เกี่ยงงอนมากเกินจนดูไม่ยินยอม

### 9.2 ควรทำ
- บรรยายอารมณ์ควบคู่การกระทำ
- ให้ตัวละครมี chemistry
- มีความยินยอมชัดเจน (แม้จะปากแข็ง)
- จบฉากด้วยความรู้สึก ไม่ใช่แค่การกระทำ
- Inner thought แสดงว่านางเอกอยากจริงๆ

```markdown

"[บทเกี่ยงงอน]" [ใบเฟิร์น] [ดื้อ/ต่อต้าน]

[ภูผา] [ตอบ/ยียวน] "[บทยียวน]"

[Inner thought ของใบเฟิร์น — ความจริงที่ซ่อน]

[การเปลื้องผ้า - บรรยายละเอียด + ความอาย]

[Foreplay - ใช้มือ/ปาก + บทเกี่ยงงอนรอบสอง]

"[เสียงคราง + บทดื้อ]" [ใบเฟิร์น]

[Afterglow - กลับมาดื้ออีกครั้ง แต่หวานขึ้น]
```

## 13. ตัวอย่างบทสนทนาสำหรับ ใบเฟิร์น & ภูผา

### 13.1 ตอนเริ่ม
```
ภูผา: (จูบแก้ม) "คิดถึง"
ใบเฟิร์น: "ไม่ได้คิดถึง"
ภูผา: "แต่หน้าแดง"
ใบเฟิร์น: "ก็... ก็ร้อน"
ภูผา: "งั้นถอดเสื้อสิ" (ยิ้ม)
ใบเฟิร์น: "บ้า!" (แต่ไม่ได้ผลัก)
```

### 13.2 ตอน Foreplay
```
ภูผา: "เสียวไหม"
ใบเฟิร์น: "ไม่... อื้อ..."
ภูผา: "ไม่เหรอ งั้นหยุดนะ"
ใบเฟิร์น: "ใครให้หยุด!"
ภูผา: "ก็บอกว่าไม่เสียว"
ใบเฟิร์น: "...ก็นิดหน่อย"
ภูผา: "นิดเดียวเหรอ" (ทำต่อ)
ใบเฟิร์น: "อา... ก็... มากหน่อย..."
```

### 13.3 ตอนใกล้ไคลแม็กซ์
```
ใบเฟิร์น: "ภูผา... อือ... จะ..."
ภูผา: "จะอะไร บอกมา"
ใบเฟิร์น: "ไม่... ไม่บอก... อา!"
ภูผา: "บอกมา ถึงจะให้"
ใบเฟิร์น: "จะ... จะถึงแล้ว... ขอร้อง..."
```

### 13.4 ตอน Afterglow
```
ภูผา: (กอด) "รักนะ"
ใบเฟิร์น: "...ก็รู้"
ภูผา: "ไม่พูดเหรอ"
ใบเฟิร์น: "ไม่"
ภูผา: "งั้นจะทำอีกรอบ จนกว่าจะพูด"
ใบเฟิร์น: "บ้า! ...ก็รัก"
ภูผา: (จูบหน้าผาก) "น่ารัก"
ใบเฟิร์น: "ไม่ได้น่ารัก"
```
